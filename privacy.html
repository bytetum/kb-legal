Privacy Policy

Last updated: 12 November 2026

What this app is

bytetum-calendar is a personal application run by its developer for their own use. It accesses Google Calendar data of the developer's own Google account only.

Data accessed

With the developer's permission, the app uses the Google Calendar API to read calendar events and, where granted, create or change them.

How data is used and stored

  • Calendar data is used only to provide the app's calendar features to the developer.
  • Data is processed and stored on the developer's own computers and servers. It is not sold, rented or shared with third parties, and it is not used for advertising.
  • No human reads the data except the developer, who owns it.

Google API Services User Data Policy

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deleting data

Access can be revoked at any time at myaccount.google.com/permissions. Stored copies of calendar data can be deleted by the developer on request.

Contact

Open an issue at github.com/bytetum/calendar-app/issues.
