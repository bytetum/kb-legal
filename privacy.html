Privacy Policy

Last updated: 12 November 2026

What this app is

bytetum kb is a personal knowledge base run by its owner for their own use. Its calendar sync accesses Google Calendar data of the owner's own Google account only.

Data accessed

With the owner's permission, the app uses the Google Calendar API with the scope calendar.app.created. This lets it create calendars and read and write events in the calendars that the app itself created. It does not read the owner's other calendars.

How data is used and stored

  • Calendar data is used only to keep the owner's kb and these calendars in sync.
  • Data and Google sign-in credentials are stored on the owner's own computers and servers, in the app's own data directory and secret store. Nothing is sold, rented or shared with third parties, and nothing is used for advertising.
  • No human reads the data except the owner.

Google API Services User Data Policy

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deleting data

Access can be revoked at any time from inside the app (Remove on the sync service) or at myaccount.google.com/permissions. Stored copies of calendar data can be deleted by the owner at any time.

Contact
